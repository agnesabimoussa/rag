# Description
Pipeline: Source documents -> Chunking -> Indexing -> retrieval -> evaluation
or: Source documents -> Chunking -> Indexing -> retrieval -> generation -> answer
1) Chunking
Documents we receive contain very big data, we need
some way to organize them in order to retrieve the relevant text faster. We chunk mardown files by applying structure-based chunking, and we chunk
code files by dividing them by function / class.
2) Indexing
bm25 is a lexical based information-retrieval algorithm (based on exact keyword matching)
